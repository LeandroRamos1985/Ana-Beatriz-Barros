## Publicação
Pode ser publicado em GitHub Pages, Hostinger ou outra hospedagem estática.

Antes de produção:
- definir domínio;
- incluir canonical e sitemap final;
- validar SSL;
- executar Lighthouse na URL publicada;
- configurar analytics/Search Console/CRM somente quando houver dados reais;
- revisar conteúdo com a profissional.

## Observação importante
Os retratos usados nesta demonstração foram reconstruídos/melhorados a partir dos prints enviados pelo usuário. Para produção final, arquivos originais em alta resolução são preferíveis.
